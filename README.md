# AlphaMath CSEC Mathematics — Sanitized Reviewer Demonstration

This repository is a public-review build of a static educational prototype.

## Privacy and content boundary

- No real student identity, roster mapping, submitted response, or saved learner record is included.
- `REVIEW-DEMO` is a fictional interface identifier.
- Interactive answers remain in the reviewer’s browser through `localStorage`; this build has no response database or analytics.
- The tutorial and simulated exam use tutor-authored bridge questions only.
- Reproduced CSEC past-paper questions are intentionally excluded from this public build.
- CSEC® and CXC® are referenced only to describe curriculum alignment. This demonstration is not affiliated with or endorsed by CXC.

## Pages

- `index.html` — review entry point
- `intake.html` — syllabus-aligned intake interface
- `learning-path.html` — illustrative mastery pathway
- `tutorial.html` — tutor-authored proportional-reasoning tutorial
- `simulated-exam.html` — reviewer-safe ten-question interaction demonstration
- `math-input.html` — local math-entry prototype
