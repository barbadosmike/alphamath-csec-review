Accounts requesting access

Signed in as . Approving grants a tutor account that can read the evidence of every learner assigned to it. A request holds its own password — you never see or set it.

Accounts

Active accounts

Suspending an account revokes every live session it holds — permanently, in the same act — and blocks sign-in. Assignments are kept, so reinstating restores the tutor's roster; their old sessions are never restored.

Learners · 0 registered

Learner records

Register a learner

The learner ID is the subject-scoped identifier the whole system runs on — M-STU-002, AM-STU-002. Name, school and email are optional, and the tutor workspace never displays them.

Assignments

Assign a learner to a tutor

An assignment is what lets a tutor read that learner's evidence — the server re-checks it on every request. Nothing else grants access.

Parent links

Link a parent to a learner

The link is what lets a parent read that child's progress — the server re-checks it on every request, exactly as it does tutor assignments. Parents cannot link themselves.
