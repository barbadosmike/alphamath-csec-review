Check the CSEC Mathematics foundation first

Additional Mathematics assumes fluent fraction arithmetic, algebraic manipulation, index laws, solving linear and quadratic equations, and coordinate gradients. If one of these foundations is not yet secure, record the Add Maths topic honestly and repair the prerequisite through the CSEC Mathematics pathway before continuing.

Read this before you tick a single box

A right answer with no working scores badly on Paper 2. A wrong answer with clear, correct working still earns method marks. So the test for "I can do this" is not can I get the answer — it is:

Can I write Given that… → name the operation before I do it → one step per line, equals signs aligned → a Check line → ∴ and a boxed final answer with its units?

If you cannot do that yet, choose “Needs practice.”
